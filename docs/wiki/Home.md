# ~/workspace

A private, terminal-themed workspace that runs in the browser: a diary, the
notes for work and for uni, a board per space, and the files that go with them.
One user, one SQLite file, one binary. Everything is a key or a `:` command on
the desktop, and a button on the phone.

![A document open in the reader](../images/document.png)

## Where to start

- **[Getting started](Getting-Started.md)**: run it, log in, find your way
  around in the first ten minutes.
- **[The guide](Guide.md)**: a day with the workspace, from the morning's
  agenda to the evening's diary entry, with every part explained on the way.
- **[Keys and commands](Commands.md)**: the full list, the same one `?` shows.
